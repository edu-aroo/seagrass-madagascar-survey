Photos de la page (bandeau, accueil, sections, remerciements).
Par défaut, la page charge les photos depuis Wikimedia Commons. Pour les héberger
avec le site (recommandé : plus rapide, indépendant de Wikimedia), lancer une fois
dans R depuis le dossier enquete-herbiers/ :  source("tools/download_photos.R")
Les fichiers sont alors enregistrés ici sous le nom indiqué dans SURVEY.PHOTOS (key.jpg).

ou domaine public — auteur indiqué pour chaque photo dans survey-config.js
(Symbiosis, Diego Delso, Stéphane Lesbats / Ifremer, Bernard Dupont, James St. John,
Furkon & L. Cullen-Unsworth, NASA / Kim Shiflett).
L'attribution (auteur + licence + lien) est affichée sur chaque photo : ne pas la retirer.
Vos propres photos de terrain malgaches seraient préférables : les déposer ici et mettre
à jour src / caption / credit / license / page dans survey-config.js.
